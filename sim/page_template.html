Spike Express Lanes

A trained spiking network runs on several neuromorphic "cores". Every spike that leaves a core normally waits on one shared electronic bus. Here the photonic chip's MZI mesh, used as a on waveguide rows , is reconfigured every few milliseconds to carry the busiest core-to-core flows as light, and the bus handles the rest.

Is the mesh a router or fixed? A router, but a slow one. Its phase-shifter settings decide which input port's light reaches which output photodiode. Between reconfigurations it behaves like fixed optical wires. Here a computer re-picks the setting once per window (slider below), which is compatible with thermo-optic phase shifters.

How the neurons are split

The network is 2312 input pixels → 128 hidden → 64 hidden → 10 outputs, trained on N-MNIST-style events. Each core hosts a group of neurons. A spike leaving a core becomes one packet per other core that holds a target neuron.

The one rule the mesh follows

Each output photodiode may listen to only one sending core per setting, because light from two senders adds up and the receiver can no longer tell who fired. Within that rule any pattern works:

  • The chip uses each MZI only as BAR, CROSS or 50:50, so split branches never recombine and no phase calibration beyond these three states is needed.
  • One-to-one routes: every permutation of the cores is reachable.
  • Multicast: equal splits built from 50:50 stages ().
  • Multicast to exactly 3 cores would need a 1/3 split, so of the patterns are reachable. For this network's traffic the best reachable setting always carries as much as an unrestricted mesh would.

Each window, the controller picks the reachable setting that carries the most traffic.

What this is and isn't

  • The SNN is real and trained here (test accuracy ).
  • The bus is a single queue. Real AER networks have more structure, so treat delays as relative.
  • Input-layer spikes dominate the traffic. On a real chip, sensor input may arrive through its own port.
  • Partitioning matters more than adaptivity. Switch to random placement to see offload fall.
